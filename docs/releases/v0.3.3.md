## 当前能力与边界

0.3.3 包含本地项目与会话、流式任务、工具/澄清/写入授权、Crossref 元数据检索、研究笔记、自有模型供应商和自定义端点，以及工作区文本编辑、Markdown/PDF/图片预览。

PDF 当前是阅读预览，尚未作为模型可按页引用的全文资料。文本保存使用单份 `.bak`，没有外部修改冲突检查；agent 的路径与敏感文件策略仍需与桌面路径统一。后续科研资料闭环将在开发分支实现，不覆盖本次 0.3.3 产物。
